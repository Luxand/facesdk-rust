This directory contains the iBeta liveness license key.
Install it before running liverecognition on Windows or Linux.

Windows:

    run_to_install_license.bat

or

    install_license_windows.exe prod-pad-license-2027-06-28.usermode.v2c

Linux:

    sh INSTALL.sh

or

    ./install_license_linux *.usermode.v2c
